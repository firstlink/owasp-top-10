# Defense Scenario Transcripts

These transcripts are for the shared defense walkthroughs shown on each ASI category page.

They intentionally do **not** mirror the attack transcripts line-for-line.

The attack transcripts are built around:

- how the failure happens
- where trust breaks
- how the wrong action executes

These defense transcripts are built around:

- how the same business workflow can stay useful
- where layered controls intervene
- how multiple defenses combine into a safe outcome

Shared-defense rule:

- Use one representative attack scenario as the frame.
- Mention the other variants once near the beginning.
- Do not repeatedly re-explain all three attacks.
- Keep the teaching energy on the defense path.
